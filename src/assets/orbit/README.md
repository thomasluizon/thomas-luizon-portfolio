# Orbit assets

`orbit-lockup.svg` comes from the Orbit landing page's canonical lockup. The paths and ink bounds are preserved; the external image uses fixed foreground and moon colors.

`product-preview.png` captures the existing landing-page demo in English, with the development toolbar hidden. It illustrates the product, rather than a user's account. The visible caption identifies the source as a product demo.

Source: [Orbit landing-page assets and demo](https://github.com/thomasluizon/orbit-landing-page/tree/53f577479d6193042a89bb41f20e8bd25fc71218).

The section uses the product's local Geist and Space Grotesk font files. Their licenses are distributed in `public/fonts`.
