# Thomas Luizon Portfolio

Astro-based personal portfolio for Thomas Luizon. The site is a one-page portfolio that presents Thomas as a senior full-stack engineer with strong AI, cloud, and infrastructure depth, while featuring Orbit as the main case study.

English is the default language. Portuguese is an option in the language switch. The site saves the language only when a visitor picks one.

## Stack

- Astro
- TypeScript
- Tailwind CSS v4
- GSAP + ScrollTrigger

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```
